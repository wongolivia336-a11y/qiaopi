# 《一封侨批，抵达之后》数据契约 v1

> 目的：把侨批课程作业从“整页视觉草图”收敛为三张 A0 海报可复核的数据叙事。本文规定每张海报回答什么问题、使用哪些真实字段、图形如何编码、哪些结论可以说、哪些结论不能说。

## 0. 数据边界与来源

- **原始来源**：本地课程源文件《侨批可用数据.xlsx》（原始文件不公开，具体本机路径不写入仓库）。
- **当前发布摘要**：`课程资料/侨批可用数据-summary-v3.js`，以 `window.QIAOPI_DATA` 形式保存字段级聚合，不是原始 Excel。
- **摘要覆盖量**：`total = 50,064` 条记录；各聚合表原则上都应能回算或解释到该总量，缺失值以 `未知` 表示。
- **公开边界**：当前仓库公开的是摘要脚本和可视化，不上传原始 Excel。若摘要中包含人名或可识别字段，后续发布前需再次确认公开授权。
- **地理边界**：Excel 的地点名称不是经纬度。HTML 中的 `originCoord`、`countyCoord`（以及国家名归一化）属于外部地理字典/人工匹配，必须在最终海报中标注“地理位置为名称匹配后的制图坐标”，不能伪装成原始字段。
- **缺失值边界**：`未知` 是资料未记录、无法识别或未完成整理，不是一个真实国家、县或批局；统计时可单独显示，但不应被称为“未知地区的通信偏好”。

## 1. 统一编码规则

### 1.1 记录单位

所有 `count`、`数量`、`记录数` 的单位都是**侨批记录条数**，不是人数、金额、信件重量、航次或人口。

### 1.2 颜色与线宽

- 灰蓝：全库路径或次要路径；砖红：被选中的路径/重点对比，不默认表示“更重要”或“更真实”。
- 线宽使用 `sqrt(count)` 或明确比例尺，防止大流量把小流量完全压没。
- 颜色不能作为唯一编码；必须同时提供标题、图例、坐标或直接标签。

### 1.3 日期可信度

摘要中的 `confidence` 为全库汇总：

| 类别 | 条数 | 含义 |
|---|---:|---|
| 直读 | 31,083 | 日期/年份可直接从记录或原件字段读取（需以原始数据字典最终确认） |
| 无年 | 11,766 | 记录中没有可用年份 |
| 推断待核 | 7,215 | 年份来自推断、规则或待核字段，不得与直读年份混为一谈 |

三者合计 50,064。任何按年份绘制的图必须说明：无年记录被排除在时间轴之外，推断记录单独标识。

## 2. 三张 A0 海报的总体叙事

三张不是三张独立信息图，而是一封信的三个状态：

1. **01 此岸｜起信**：信从哪些海外来源地出发，最终对应哪些潮汕收批县？
2. **02 中途｜经批局**：在来源地和收批县之间，哪些批局/中介节点实际承接了路径？
3. **03 彼岸｜抵达**：记录在时间上如何变化，字段的可信程度如何，宏观网络如何落到寄批人—收批县关系与一封家书？

三张共享一条砖红叙事线，但必须标注：

> 砖红线＝跨面板叙事索引，固定线宽且不编码数量；灰蓝线＝当前摘要表中纳入制图的聚合路径。现有摘要没有贯通三页的单件 EID，故砖红线不能称为单件真实行程或统计代表路径。

## 3. 海报 01｜此岸·起信：跨海路径不是平均分布

### 3.1 主张

“潮汕人下南洋”过于笼统。数据可以检验：海外来源地与收批县之间是否存在明显的非均衡连接，以及不同收批县的来源地集中度是否不同。

### 3.2 主图：来源地 → 收批县地理流向图

**数据集**：`flows`。

| 视觉元素 | 字段 | 编码/单位 | 备注 |
|---|---|---|---|
| 起点 | `source` | 国家/地区名称，类别型 | 先统一“印度尼西亚/印尼”等同义名；`未知` 单独处理 |
| 终点 | `county` | 收批县名称，类别型 | `未知` 不放入正式地图节点，另列缺失统计 |
| 线 | `count` | 记录条数 | 线宽∝√count；必须有线宽图例 |
| 节点 | 同一 `source` 或 `county` 的 `count` 汇总 | 记录条数 | 节点面积∝总记录数，不等同人口或港口规模 |
| 位置 | 外部坐标字典 | 经度/纬度，度 | 必须标注“名称匹配坐标”及坐标来源 |

**已知数据事实（当前摘要）**：

- 总记录 50,064；来源地为 `未知` 的 796 条，已知来源地合计 49,268。`flows` 聚合表当前合计 50,062，比全库少 2 条，制图必须单独披露该差额。
- 最大组合为：新加坡→潮安 14,505；泰国→澄海 12,781；泰国→潮安 7,880；马来西亚→潮安 3,978；新加坡→澄海 2,786。
- 这些数字支持“连接高度不均衡”，但不能直接支持“某地一定有更大移民人口”或“路线一定经过某个港口”。

**海报图注建议**：

> 线宽为侨批记录条数，不是船运量；地图位置由地点名称匹配坐标，仅用于显示空间关系。

### 3.3 证据图：来源国 × 收批县矩阵

**数据集**：仍为 `flows`，透视为行=`source`、列=`county`、单元格=`count`。

- 圆面积或色深＝记录条数；必须显示行列标签和单位。
- 建议排除 `未知` 行列，另以缺失卡片显示：来源 796 条、收批县 683 条。
- 该图用来验证地图的“线多”是否只是视觉叠加：读者可直接看到组合差异。

### 3.4 证据图：收批县来源集中度

**计算**：对每个收批县 `c`，从 `flows` 中取已知 `source` 的计数 `n_i`，`p_i=n_i/Σn_i`，使用归一化 Shannon entropy：

`H_norm(c) = -Σ p_i log(p_i) / log(k)`，其中 `k` 为该县出现的已知来源地数量。

- 范围 0–1；越低表示记录更集中在少数来源地，越高表示来源更分散。
- 必须写清“这是来源结构的集中度，不是文化多样性、人口多样性或社会开放程度”。
- 将“印尼”归一为“印度尼西亚”后，当前摘要计算示例：潮安 0.524260、澄海 0.379302、揭阳 0.655098、饶平 0.247940、普宁 0.251201。未知来源排除，`k` 按归一化后的正计数已知来源类别数计算。

### 3.5 本页不应出现

- 没有数据支持的“港口实际航线”“航行时长”“季风方向”。
- 将经纬度连线解释为真实航路；当前 `flows` 只有来源地和收批县两个端点。
- 用 AI 生成的地图文字、地名或边界作为数据。

## 4. 海报 02｜中途·经批局：信如何穿过中介网络

### 4.1 主张

批局不是抽象的“物流中心”，而是数据中可被观察到的中介节点。应该比较不同来源地—批局—收批县三元关系的记录规模、覆盖范围和集中度。

### 4.2 主图：来源地—批局—收批县三段 Threads

**数据集**：`routeTriples`。

| 视觉元素 | 字段 | 编码/单位 | 备注 |
|---|---|---|---|
| 左列节点 | `source` | 海外来源地 | 类别型 |
| 中列节点 | `office` | 批局/批号/中介名称 | 类别型；`未知` 应单列或过滤 |
| 右列节点 | `county` | 收批县 | 类别型 |
| 连接 | 三字段组合 | 一条真实聚合组合 | 不是每一封信的逐件路径 |
| 线宽 | `count` | 记录条数 | 建议∝√count；显示 Top-N 并注明截断规则 |

**当前摘要示例**：泰国→未知批局→澄海 9,483；泰国→未知批局→潮安 5,806；新加坡→未知批局→潮安 3,637；新加坡→万益成→潮安 1,267。由于批局缺失量较大，不能把所有路径都讲成“经某批局转运”。

**缺失提示**：`offices` 中批局为 `未知` 的记录为 25,374 条，约占全库 50.7%。正式海报应把“批局可识别网络”与“批局缺失记录”并列呈现。

### 4.2b CSV-backed 竖向版本（2026-10-17）

为接入用户补充的清洗表，P02 新增 `threads-vertical` 版本。主流量来自 `B_人物字段清洗后.csv`：`EID` 作为逐记录存在性检查，路线字段使用 `寄批国家地区_统一`／`寄批国家或地区`、`批局主体名`／`批局完整名称`、`收批县域_统一`／`收批县`。B 表仍为 50,064 条，三段字段同时可识别的记录为 24,068 条；`新加坡 → 万益成 → 潮安` 为 1,267 条真实组合。

`A_人物字段清洗后.csv`（13,578 条）与 B 表没有稳定跨表键，题名精确重合只有 7 个唯一值；A 只用于人物字段审计，不用于补造来源—批局—收批县路径。批局字段含 1,601 条复合串列，图面保留复合键，不推断内部先后。

竖向 SVG 的带宽仍代表记录条数，红色只标注叙事样本；地图剪影仅作装饰，`未记录` 与 `其他` 必须保留并解释。

### 4.3 证据图：批局覆盖范围与县域组合

**数据集**：`officeCounty`。

- 横轴建议拆成两个明确指标：
  1. 批局总记录数：按 `office` 汇总 `count`；
  2. 已知收批县数量：对每个 `office` 统计不同 `county` 数量。
- 不要把“覆盖县数”和“记录量”叠成无单位的综合分数。
- `未知` 批局不要进入“批局排名”，另列为数据缺失占比。

### 4.4 可选证据图：批局—县 radial / network

只能使用 `officeCounty` 的真实边和 `count`。中心节点大小＝批局总记录数，外圈节点＝收批县，边宽＝组合记录数。建议最多展示 Top 8 批局与 Top 6 县，并明确写“展示 Top-N，非完整网络”。

### 4.5 本页不应出现

- “信用网络与快递网络结构不同”的比较图，除非有独立的网络边、时间、金额或文本字段。当前 HTML 的 `compare` 只是四条概念线，数据没有提供它的数值依据，应删除。
- “节点介数中心性、节点失效影响、替代路径”等结论。摘要没有逐件有向边、时序或可替代性实验数据；可以写进后续研究计划，不能作为本次海报事实。
- 把“批局”直接等同于官方邮政机构或现代物流网点。

## 5. 海报 03｜彼岸·抵达：记录如何随时间变化并落到个人

本页合并 HTML 原来的“03 数量与可信度”和“04 关系与月份”，以避免四页叙事在 A0 三联中断裂。

### 5.1 主图：年度记录量与日期可信度分轨

**数据集**：`yearStats`。

| 视觉元素 | 字段 | 编码/单位 |
|---|---|---|
| 年度横轴 | `year` | 公历年份；只显示可用年份 |
| 记录量 | `count` | 条数；柱或面积 |
| 日期直读 | `direct/count` | 百分比 |
| 推断待核 | `inferred/count` | 百分比 |

`无年`不绘制到任何具体年份，应以独立缺失卡片显示 11,766 条。年度数据包含 2020 年 785 条，不能擅自剪掉；若研究只讨论历史侨批，应在筛选规则中明确排除并报告排除量。

当前 HTML 的 1937、1939、1945 事件竖线属于外部历史语境，不来自 Excel。若保留，必须增加事件来源；否则删掉，避免把外部史实与数据变化混为因果关系。

### 5.2 证据图：年份 × 月份热力图

**数据集**：`calendar`。

- 横轴=`year`，纵轴=`month`（1–12 月），色深=`count` 条记录。
- 未出现的组合表示“摘要中没有记录”，不等同于“当月没有寄信”；使用空白/NA，而不是零色块。
- 当前数据中 1 月出现很多高值（例如 1973 年 1 月 323 条），只能说“档案记录密度高”，不能直接解释为春节寄信或季节性习俗，除非有外部文献或原始日期核验。

### 5.3 证据图：寄批人—收批县关系时间线

**数据集**：`senderCounty`。

- 行=`sender` + `county`；点/线段=`start`、`end`；`count`＝该组合记录条数。
- `start/end` 是摘要提供的首末年份，不是每一笔记录的连续通信轨迹。
- 目前摘要只保存 Top 30 组合；不能由两个端点推断中间每年都有记录。
- 如果要画“中断/恢复”，必须回到逐条原始数据，根据年份集合计算空窗区间，并把空窗解释为“档案中无记录”，而非通信中断。

### 5.4 个人化落点：寄批人/称谓/家书卡片

- `senders` 和 `recipientIdentities` 是各自的全库频数榜，不包含逐条对应关系；不能把“母亲 12,442 条”连接成某个具体寄批人的母亲。
- 真实的个人卡片必须从原始记录中选定一条 EID，并展示该条记录实际拥有的年份、来源、批局、收批县、收件称谓与文本字段。
- 当前 HTML 中的“伏惟家慈亲福体安康……”是示意文本，不能作为档案原文。正式海报必须替换为获授权的原件图像/释文，并保留 EID、出处和释读状态。

### 5.5 本页不应出现

- 金额走势、汇款总额、物品种类或文本情感曲线：当前摘要没有金额、物品和全文字段。
- 把月度高密度解释成节日、战争、汇兑政策等因果关系；先做相关性描述，再补外部来源。
- 把 `start/end` 画成连续家族谱系或“半生通信不断”。目前只能表达摘要层的最早/最晚记录。

## 6. 当前 HTML 审计：可保留、需重做、应删除

### 可保留（重标注后）

- `map`：逻辑正确，数据来自 `flows`；需要补齐坐标字典来源、比例尺、未知值说明。
- `matrix`：逻辑正确，数据来自 `flows`；需补轴标题、单位、色/面积图例，并统一国家名。
- `profile`：可以保留，前提是固定熵公式、说明排除未知值与 `k` 的定义，并在最终版提供计算脚本。
- `threads`：数据来自 `routeTriples`；需把 `未知` 批局单独处理，并说明 Top-N/聚合层级。
- `times`：数据来自 `yearStats`；需拆开条数和百分比坐标，显示无年及推断值。
- `stream`：数据来自 `yearSource`；可以作为来源构成辅助图，但需要解释 silhouette baseline，不宜说“总厚度”而没有单位轴。
- `calendar`：数据来自 `calendar`；需以 NA 区分无记录和零值。

### 需重做后才能进入最终海报

- `radial`：当前绘制使用 `for (let i=0;i<46;i++)` 和 `(i*7)%hubs.length` 人工分配外圈边，未读取 `officeCounty` 的真实边和 `count`；目前是形状占位，不是数据图。
- `lineage`：当 `REAL` 存在时，`pairs` 把 `gaps` 固定为 `[]`，且 `start/end` 只来自汇总端点；标题“持续、中断与恢复”超出了数据证据。需回到逐条记录重算，或改名为“高频寄批人—收批县的记录覆盖区间”。
- `scatter`：当前图是年度 `count` 与日期直读比例的散点，理论上可计算，但要明确样本单位是“年份”、排除规则和相关性检验；若没有要讲的统计关系，应删掉以节省版面。

### 应删除或改为文字旁注

- `compare`：四条“海外端/批局/批脚/信＋款”线没有任何数值字段或网络结构支撑，属于概念图，不应被当作数据可视化。
- HTML 中将金额、钱款或“信＋款”写成事实的任何图形：当前摘要没有金额字段；只能作为未来数据需求。
- HTML 中未经出处的“全面抗战、汕头沦陷、航路恢复”等事件标签：可以保留为外部语境，但必须另列史料来源，并避免暗示因果。

## 7. 最小可交付数据字典

| 数据表 | 主键/组合键 | 可支持的图形 | 不可支持的结论 |
|---|---|---|---|
| `sourceCountries` | `source` | 来源地榜、比例条形 | 人口规模、移民规模 |
| `counties` | `county` | 收批县榜、地图节点 | 村落级落点、人口 |

## 8. 交付检查清单

- [ ] 每张 A0 只有一个主图，所有辅助图都能回答一个具体问题。
- [ ] 每个图有标题、单位、图例、坐标/标签、数据来源和缺失值说明。
- [ ] 地图中的线被标为“端点关系”，不冒充真实航线。
- [ ] 所有 `未知` 均被单独解释，不混入“真实国家/县/批局”。
- [ ] 年份图把直读、推断、无年分开；无年不被强行放进某一年。
- [ ] PNG 只承担档案物件；标题、轴、图例、数字和地图由 SVG/Figma 重绘。
- [ ] 砖红叙事索引与灰蓝摘要统计线有不同图例，避免把聚合组合冒充单件个案或全库总量。
- [ ] 所有真人姓名、原件图像、释文和 EID 在公开前完成授权核验。
- [ ] 最终 SVG 与数据版本绑定，记录生成日期、摘要脚本版本和清洗规则。

## 审计结论

当前 HTML 是很好的四章节探索稿，但不是可以直接印成三张 A0 的最终数据稿。最值得保留的证据链是：`flows → map/matrix/profile`、`routeTriples/officeCounty → threads/office network`、`yearStats/calendar → time/heatmap`、`senderCounty → relationship coverage`。必须删除或降级为旁注的部分是概念性 `compare`、未读取真实边的 `radial`、把空窗写成中断恢复的 `lineage`，以及在没有金额/物品/全文字段时暗示“信＋款”“金钱流”的表达。

最终三联海报的核心不是“把所有图表摆满”，而是用三次可复核的证据推进同一个问题：**这封信从哪里来，经过哪些可观察的中介关系，最终在怎样的时间与家庭关系中留下记录？**
