# Source bundle

本目录对应本轮可追溯使用的三份源文件：

- `A_人物字段清洗后.csv`：人物与字段清洗上下文，13,578 行。
- `B_人物字段清洗后.csv`：侨批记录主表，50,064 行；P02 三段路径的主数据源。
- `侨批可用数据(1).xlsx`：课程提供的原始工作簿，用于核对字段与来源。

P02 当前恢复为竖向 CSV Sankey v2；A 表与 B 表不强行拼接，当前派生数据位于 `data/derived/panel-02-sankey-derived-v2-csv.json`。公开仓库包含源文件是用户本轮明确授权的交付范围；若后续扩大公开范围，应再次核验其中的姓名、地址与档案识别字段。
