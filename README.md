# 侨批数据可视化｜一封侨批，抵达之后

这是一个数据优先的侨批可视化项目，目标是把一封侨批从海外寄批地、批局网络讲到潮汕村庄与家书。

## Data boundary

仓库公开的是字段级摘要脚本和可视化资源，不上传原始 Excel。图表必须从数据契约生成，所有坐标轴、图例、单位、来源与缺失值说明都需要保留。

## Production direction

最终交付为三张相互连接的 A0 竖版海报：

1. 此岸｜起信：来源地与潮汕收批县的空间分化；
2. 中途｜经批局：海外来源—批局—收批县的真实网络；
3. 彼岸｜抵达：时间、日期可信度、长期关系与一封具体家书。
