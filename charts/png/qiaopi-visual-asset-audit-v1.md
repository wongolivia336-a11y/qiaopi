# 三联海报视觉资产走查与结构素材 v1

本轮不是继续生成整页海报，而是针对参考三联图逐层检查“物件、结构、底图、装饰”四类视觉缺口。新增素材均为生成式氛围资产，不是历史档案，不得配上虚构店名、日期、人物身份、邮戳文字或档案编号。

## 走查结论

已有资产已经覆盖主要叙事物件：信封、印泥木印、邮袋木箱、木棉花枝、批局门面、书信桌面、伏案写信人物。当前最影响三张海报完整度的不是更多具体物件，而是“让图表像被放在旧档案桌面上”的结构层：撕纸边、照片装裱、账页线、无字邮戳环、灰蓝底纹和窗格/墙面边角。

## 组合规则

- 这些 PNG 只负责材质、层次和边界，不承载事实；所有标题、数字、县名、图例、地图和统计线必须保留为可编辑文本/SVG。
- 灰蓝底纹只能营造“海域/旧纸染色”的气氛；真实数量仍由灰蓝统计线、圆点或矩阵格表达。
- 砖红线、代表性侨批路径和跨栏连接应在 Figma/SVG 中绘制，不能用生成的红线 PNG 固化。
- 结构资产建议先去饱和、降低对比，再以 15–55% 不透明度叠放；禁止发光、渐变、玻璃拟态和高饱和蓝橙。
- Figma `04_PNG Assets` 页统一命名为 `GENERATED/<asset-name>`，并标记 `GENERATED ATMOSPHERE / 非档案原件`。

## 仍然不生成的元素

- 红色路线/红线：需要保持可编辑，并区分全库真实统计与叙事样本路径。
- 地图、矩阵、集中度、时间序列、热力格、关系网络：由数据 SVG 负责。
- 中文印章、店名、日期、人物身份和可读手写信：生成模型容易制造伪事实，改由人工排版或真实授权档案替换。
